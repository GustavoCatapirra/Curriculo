CURRÍCULO MODERNO — GUSTAVO CATAPIRRA DIAS PINHEIRO

ARQUIVOS
- index.html: estrutura e conteúdo do currículo.
- style.css: identidade visual, layout responsivo, animações e estilo de impressão.
- script.js: alternância de tema, efeitos de entrada, navegação e impressão.

COMO ABRIR
1. Extraia o ZIP para uma pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador. A extensão Live Server também funciona muito bem.

COMO SALVAR EM PDF
Clique em “Salvar / imprimir” no topo e escolha “Salvar como PDF” na janela de impressão.

ANTES DE ENVIAR O CURRÍCULO
- Revise telefone, e-mail e link do LinkedIn.
- Confirme a disponibilidade de horário.
- Complete a seção “Projetos tecnológicos” com um projeto real.
- Confirme os nomes e os níveis das competências e ferramentas listadas.
- Os indicadores visuais dos idiomas são apenas ilustrativos; os níveis textuais foram mantidos conforme informados.

OBSERVAÇÃO
O Google Fonts é carregado pela internet. Se não houver conexão, a página usa fontes alternativas do sistema.
